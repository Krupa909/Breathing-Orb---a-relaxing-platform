Breathing Orb
=============

How to run:
1. Unzip this folder.
2. Double-click index.html (opens in your browser).

Keep index.html and three.min.js in the same folder.
Sound starts after your first tap. Fonts load from Google Fonts when online; the page falls back to system fonts offline.
To put it online, upload both files to any static host (Netlify, GitHub Pages, Vercel).
